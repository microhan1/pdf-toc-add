PDF 목차 넣기

스캔한 책 PDF에 북마크(목차)를 넣어서 원하는 장으로 바로 건너뛸 수 있게 해 줍니다.

준비물

  • pdf_toc_add.exe — 설치 필요 없이 그냥 실행됩니다.
  • 스캔한 책 PDF
  • 목차를 적은 텍스트 파일 (메모장으로 만들면 됩니다). 창에서 직접 타이핑해도 됩니다.

1. 목차 텍스트 만들기

한 줄에 항목 하나씩 제목, 쪽수 를 적습니다.

offset=8

머리말, 1
1장 서론, 12쪽
    1.1 배경, 13
    1.2 목적, 15
2장 본론, 25
    2.1 방법, 26
        2.1.1 세부 방법, 27
    2.2 결과, 31
3장 결론, 40
찾아보기, 52
  • 줄 끝의 숫자를 쪽수로 읽습니다. 쉼표, 탭, 점선(......), p., 쪽 은 있어도 없어도 됩니다.
  • 앞에 공백이나 탭을 넣어 들여쓰기하면 하위 항목이 됩니다. 몇 단계든 가능합니다.
  • # 으로 시작하는 줄과 빈 줄은 무시됩니다.
  • 메모장 기본 인코딩(ANSI/CP949), UTF-8, UTF-16 모두 자동으로 읽습니다.

2. offset (쪽수 보정) 정하기

스캔 PDF는 표지와 머리말 때문에 책에 인쇄된 쪽수와 PDF 페이지 번호가 다릅니다. PDF 뷰어에서 책의 1쪽이 PDF 몇 페이지에 있는지 확인하고, 그 차이를 offset 으로 넣습니다.

책 1쪽이 있는 곳offset
PDF 1페이지0
PDF 9페이지8
PDF 15페이지14

목차 첫 줄에 offset=8 처럼 적어 두면 파일을 열 때 자동으로 채워집니다.

3. 실행하기

pdf_toc_add.exe 를 더블클릭하면 창이 뜹니다. PDF 를 exe 아이콘 위에 끌어다 놓아도 그 PDF 가 들어간 채로 열립니다. 언어는 오른쪽 위에서 바꿀 수 있고 다음 실행 때도 기억됩니다.

  1. PDF — 창 위쪽 상자에 PDF 를 끌어다 놓습니다. 파일 이름과 페이지 수가 표시됩니다. 찾아보기… 로 골라도 됩니다.
  2. 목차 — 텍스트 파일을 창에 끌어다 놓거나 텍스트 파일 열기… 로 불러오거나, 입력칸에 직접 타이핑합니다. 예시 채우기 를 누르면 형식을 보고 고쳐 쓸 수 있습니다.
  3. offset — 쪽수 보정 값을 넣습니다.
  4. 미리보기 를 누르면 아래 결과 칸에 각 항목이 PDF 몇 페이지로 연결되는지 나옵니다.
  5. PDF 만들기 를 누릅니다.

원본 PDF 와 같은 폴더에 원본이름_toc.pdf 가 만들어집니다. 원본은 그대로 남습니다.

문제가 있으면 결과 칸에 빨간 글씨로 몇 행이 왜 잘못됐는지, 어떻게 고치는지가 나오고 목차 입력칸에서도 그 줄이 빨갛게 표시됩니다. 경고(주황)는 진행을 막지 않습니다.

이런 경우를 잡아냅니다

상황결과
줄 끝에 쪽수가 없음 (1장 서론)오류. 문제 줄을 전부 모아 행 번호와 함께 표시
로마 숫자 쪽수 (머리말 iii)오류. 아라비아 숫자로 바꾸라고 안내
숫자만 있는 줄, 쪽수 0, offset=abc오류
쪽수가 PDF 페이지 수를 넘음오류. 모든 항목이 넘으면 offset 이 너무 크다고 안내
쪽수 범위 (12-15)앞 숫자 12 사용, 경고
쪽수가 앞 항목보다 작음오타일 수 있다고 경고
목차 자리에 PDF, 이미지, Word 파일을 놓음오류. 텍스트 파일을 넣으라고 안내
PDF 자리에 PDF 가 아닌 파일, 손상된 파일, 암호 걸린 파일오류. 이유를 표시
출력 파일이 다른 프로그램에서 열려 있음오류. 닫고 다시 시도하라고 안내

4. 명령 프롬프트로 실행하기

여러 권을 한꺼번에 처리하려면 Python 스크립트를 쓰세요 (pip install pypdf 필요).

python pdf_toc_add.py 책.pdf 목차.txt
python pdf_toc_add.py 책.pdf 목차.txt --offset 8 -o 결과.pdf
python pdf_toc_add.py 책.pdf 목차.txt --dry-run
python pdf_toc_add.py 책.pdf 목차.txt --lang en
옵션설명
-o 파일출력 PDF 이름. 기본은 원본이름_toc.pdf
--offset N쪽수 보정. 목차 파일 안의 offset= 보다 우선
--dry-runPDF 를 만들지 않고 연결 결과만 표시
--keep-existing기존 북마크를 지우지 않고 뒤에 추가
--encoding 이름목차 파일 인코딩 직접 지정
--lang ko|en|zh메시지 언어. 환경변수 PDF_TOC_LANG 으로도 지정 가능

자주 묻는 것

  • 북마크가 엉뚱한 페이지로 가요. 전체가 똑같이 밀렸다면 offset, 특정 항목만 틀리면 그 줄의 쪽수 오타입니다.
  • 다시 실행하면 북마크가 두 벌 생기나요? 아니요. 기존 북마크를 지우고 새로 넣습니다.
  • Windows 가 "알 수 없는 게시자" 경고를 띄워요. 서명이 없는 exe 라 나오는 경고입니다. "추가 정보 → 실행" 을 누르면 됩니다.

PDF TOC Bookmarks

Adds bookmarks (an outline) to a scanned book PDF so you can jump straight to any chapter.

What you need

  • pdf_toc_add.exe — no installation required.
  • The scanned book PDF.
  • A text file listing the table of contents (Notepad is fine). You can also type it directly in the window.

1. Write the table of contents

One entry per line as title, page.

offset=8

Preface, 1
Chapter 1 Introduction, 12
    1.1 Background, 13
    1.2 Goals, 15
Chapter 2 Body, 25
    2.1 Method, 26
        2.1.1 Details, 27
    2.2 Results, 31
Chapter 3 Conclusion, 40
Index, 52
  • The number at the end of the line is the page. Commas, tabs, dot leaders (......), p. or page are all optional.
  • Indent a line with spaces or tabs to make it a sub-entry. Any depth works.
  • Lines starting with # and blank lines are ignored.
  • UTF-8, UTF-16 and the Windows legacy code pages (CP949, GB18030) are detected automatically.

2. Pick the offset

Because of the cover and front matter, the page number printed in the book differs from the PDF page number. Find which PDF page holds the book's page 1 and enter the difference as the offset.

Book page 1 is onoffset
PDF page 10
PDF page 98
PDF page 1514

Put offset=8 on the first line of the TOC file and it is filled in automatically when you open the file.

3. Run it

Double-click pdf_toc_add.exe. Dropping a PDF onto the exe icon opens the window with that PDF already loaded. The language can be changed at the top right and is remembered.

  1. PDF — drop the PDF into the box at the top. The file name and page count appear. Browse… works too.
  2. Table of contents — drop a text file onto the window, use Open text file…, or type directly. Fill example shows the format.
  3. Offset — enter the page offset.
  4. Press Preview to see which PDF page each entry will point to.
  5. Press Create PDF.

<name>_toc.pdf is created next to the source PDF. The source is never modified.

When something is wrong, the result box shows in red which line, why, and how to fix it, and the same line is highlighted in the TOC box. Warnings (orange) do not block the process.

What gets caught

SituationResult
No page number at the end of a line (Chapter 1 Introduction)Error. All bad lines are listed with line numbers
Roman-numeral page (Preface iii)Error, with a hint to use Arabic digits
Number-only line, page 0, offset=abcError
Page past the end of the PDFError. If every entry is past the end, the offset is flagged as too large
Page range (12-15)Uses 12, with a warning
Page smaller than the previous entryWarning (possible typo)
PDF, image or Word file dropped as the TOCError asking for a text file
Non-PDF, damaged or password-protected file as the PDFError with the reason
Output file open in another programError asking to close it and retry

4. Command line

To process many books, use the Python script (pip install pypdf).

python pdf_toc_add.py book.pdf toc.txt
python pdf_toc_add.py book.pdf toc.txt --offset 8 -o out.pdf
python pdf_toc_add.py book.pdf toc.txt --dry-run
python pdf_toc_add.py book.pdf toc.txt --lang en
OptionMeaning
-o FILEOutput PDF. Default <name>_toc.pdf
--offset NPage offset. Overrides offset= in the file
--dry-runShow the mapping without writing a PDF
--keep-existingAppend to existing bookmarks instead of replacing them
--encoding NAMEForce the TOC file encoding
--lang ko|en|zhMessage language. The PDF_TOC_LANG environment variable works too

FAQ

  • Bookmarks land on the wrong pages. If every bookmark is off by the same amount, fix the offset. If only some are off, fix those lines.
  • Does running it twice duplicate the bookmarks? No. Existing bookmarks are replaced.
  • Windows shows an "unknown publisher" warning. The exe is unsigned. Click "More info → Run anyway".

PDF 目录书签

为扫描的图书 PDF 添加书签（目录），可直接跳转到任意章节。

准备

  • pdf_toc_add.exe —— 无需安装，直接运行。
  • 扫描的图书 PDF。
  • 写有目录的文本文件（用记事本即可）。也可以直接在窗口中输入。

1. 编写目录

每行一项，格式为 标题, 页码。

offset=8

前言, 1
第1章 绪论, 12
    1.1 背景, 13
    1.2 目的, 15
第2章 正文, 25
    2.1 方法, 26
        2.1.1 细节, 27
    2.2 结果, 31
第3章 结论, 40
索引, 52
  • 行尾的数字就是页码。逗号、制表符、点线（......）、第、页 有无均可。
  • 行首加空格或制表符缩进，即为子项。 层级不限。
  • 以 # 开头的行和空行会被忽略。
  • UTF-8、UTF-16 以及 Windows 旧编码（GB18030、CP949）均可自动识别。

2. 确定 offset（页码偏移）

由于封面和前言，书上印刷的页码与 PDF 页码不一致。 在 PDF 阅读器中查看书的第 1 页位于 PDF 第几页，把差值填为 offset。

书的第 1 页位于offset
PDF 第 1 页0
PDF 第 9 页8
PDF 第 15 页14

在目录文件第一行写 offset=8，打开文件时会自动填入。

3. 运行

双击 pdf_toc_add.exe 打开窗口。把 PDF 拖到 exe 图标上，会直接带着该 PDF 打开。语言可在右上角切换，并会被记住。

  1. PDF —— 把 PDF 拖入顶部的方框，会显示文件名和页数。也可以点 浏览…。
  2. 目录 —— 把文本文件拖到窗口中、点 打开文本文件…，或直接输入。点 填入示例 可查看格式。
  3. offset —— 填入页码偏移。
  4. 点 预览，下方结果栏会显示每一项对应的 PDF 页码。
  5. 点 生成 PDF。

会在原 PDF 同一文件夹中生成 原文件名_toc.pdf。原文件不会被修改。

如有问题，结果栏会用红字显示第几行、原因和修改方法，目录输入框中对应的行也会标红。警告（橙色）不会阻止生成。

可检测的情况

情况结果
行尾没有页码（第1章 绪论）错误。列出所有问题行及行号
罗马数字页码（前言 iii）错误，并提示改为阿拉伯数字
只有数字的行、页码 0、offset=abc错误
页码超过 PDF 总页数错误。若所有项都超出，会提示 offset 过大
页码范围（12-15）使用 12，并给出警告
页码小于前一项警告（可能是笔误）
把 PDF、图片或 Word 文件当作目录拖入错误，提示需要文本文件
PDF 处放入非 PDF、损坏或加密的文件错误，并显示原因
输出文件正被其他程序打开错误，提示关闭后重试

4. 命令行

批量处理多本书时，请使用 Python 脚本（需要 pip install pypdf）。

python pdf_toc_add.py book.pdf toc.txt
python pdf_toc_add.py book.pdf toc.txt --offset 8 -o out.pdf
python pdf_toc_add.py book.pdf toc.txt --dry-run
python pdf_toc_add.py book.pdf toc.txt --lang zh
选项说明
-o 文件输出 PDF。默认 原文件名_toc.pdf
--offset N页码偏移。优先于文件中的 offset=
--dry-run只显示对应关系，不生成 PDF
--keep-existing保留已有书签并追加
--encoding 名称指定目录文件编码
--lang ko|en|zh消息语言。也可用环境变量 PDF_TOC_LANG

常见问题

  • 书签跳到了错误的页。 如果所有书签偏移量相同，请修正 offset；如果只有个别项不对，请修正那几行的页码。
  • 重复运行会产生两套书签吗？ 不会。已有书签会被替换。
  • Windows 提示“未知发布者”。 因为 exe 未签名。点击“更多信息 → 仍要运行”即可。
